## 项目说明

**项目介绍**：  
口语测评系统，服务于国内 SS（销售）组织学生口语测评场景。系统包含学生端（H5）、老师端（Web）、家长端（H5）三个终端，支持学生录音 → AI 自动评分 → 生成报告 → 老师分享给家长的全链路闭环。

**技术栈**：
- **前端**：React 19 + Vite 7 + TypeScript 5.9 + Tailwind CSS 3.4
- **后端**：Python 3.11 + FastAPI 0.109 + SQLAlchemy 2.0 + AsyncPG
- **消息队列**：RabbitMQ（aio-pika 9.3）
- **数据库**：PostgreSQL 17
- **AI 评测**：阿里云通义千问 Qwen-Omni / Qwen-Plus
- **存储**：阿里云 OSS

**访问量预估**：
- 目标支持 **1000+ QPS**（峰值）
- 支持 **5000+** 学生同时在线作答
- 预计日活跃用户：500-2000 人
