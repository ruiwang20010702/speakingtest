# 数据字段对比文档

> 模型输出 (Part 1 / Part 2) vs 家长端 H5 报告字段对照表

---

## 📊 总览

| 数据来源 | 维度数量 | 分数范围 | 用途 |
|---------|---------|---------|------|
| Part 1 模型输出 | 4 维 | 0-100 | 单词朗读评测 |
| Part 2 模型输出 | 5 维 | 0-100 | 问答对话评测 |
| 家长端 H5 报告 | 5 维 (融合) | 0-100 | 展示给家长的综合报告 |

## 1️⃣ Part 1 模型输出字段

> 来源：`backend/src/adapters/gateways/qwen_client.py` → `Part1EvaluationResult`

### 评分维度 (4 维)

| 字段名 | 中文名 | 类型 | 范围 | 说明 |
|-------|-------|------|------|------|
| `accuracy_score` | 准确度 | float | 0-100 | 单词发音是否准确，有无漏读/错读/增读 |
| `fluency_score` | 流利度 | float | 0-100 | 朗读过程是否流畅自然，衔接是否紧凑 |
| `pronunciation_score` | 发音 | float | 0-100 | 发音是否地道，元音/辅音是否清晰 |
| `integrity_score` | 完整度 | float | 0-100 | 是否读完所有内容 |

### 总分计算公式

```
total_score = (accuracy_score × 0.35) + (fluency_score × 0.25) + (pronunciation_score × 0.30) + (integrity_score × 0.10)
```

### 完整字段结构

```json
{
  "success": true,
  "total_score": 78.55,
  "accuracy_score": 78.0,
  "fluency_score": 65.0,
  "pronunciation_score": 72.0,
  "integrity_score": 100.0,
  "is_rejected": false,
  "diagnosis": "整体朗读流畅，发音清晰，但有个别单词重音有误",
  "part1_overall_suggestion": ["建议1", "建议2"],
  "details": [
    {"content": "hello", "score": 95, "issue": null},
    {"content": "world", "score": 60, "issue": "尾音发音不清"}
  ],
  "raw_response": "...",
  "usage": {"prompt_tokens": 100, "completion_tokens": 200}
}
```

### `details` 数组字段

| 字段名 | 类型 | 说明 |
|-------|------|------|
| `content` | string | 参考文本中的单词 (强制对齐，不被替换) |
| `score` | int | 该单词得分 (0-100) |
| `issue` | string \| null | 问题描述，如 "尾音发音不清" |

## 2️⃣ Part 2 模型输出字段

> 来源：`backend/src/adapters/gateways/qwen_client.py` → `Part2EvaluationResult`

### 评分维度 (5 维)

| 字段名 | 中文名 | 类型 | 范围 | 说明 |
|-------|-------|------|------|------|
| `fluency_score` | 流利度 | float | 0-100 | 语速、节奏、断句是否流畅，有无迟疑/重复 |
| `pronunciation_score` | 发音 | float | 0-100 | 发音是否准确，有无中式口音 |
| `confidence_score` | 自信度 | float | 0-100 | 声音是否洪亮，是否主动沟通 |
| `vocabulary_score` | 词汇 | float | 0-100 | 词汇发音准确率，词汇量 |
| `sentence_score` | 整句输出 | float | 0-100 | 能否输出完整句子，句式是否多样 |

### 总分计算公式

```
total_score = (fluency_score + pronunciation_score + confidence_score + vocabulary_score + sentence_score) / 5
```

### 完整字段结构

```json
{
  "success": true,
  "transcript_full": "完整转写文本...",
  "total_score": 75.0,
  "fluency_score": 70.0,
  "pronunciation_score": 75.0,
  "confidence_score": 80.0,
  "vocabulary_score": 70.0,
  "sentence_score": 80.0,
  "items": [
    {"no": 1, "transcript": "My name is Tom.", "feedback": "回答切题，但时态有误"},
    {"no": 2, "transcript": "I like apple.", "feedback": "应使用 apples (复数)"}
  ],
  "part2_overall_suggestion": ["建议1", "建议2", "建议3"],
  "raw_response": "...",
  "usage": {"prompt_tokens": 500, "completion_tokens": 800}
}
```

### `items` 数组字段 (12 题)

| 字段名 | 类型 | 说明 |
|-------|------|------|
| `no` | int | 题号 (1-12) |
| `transcript` | string | 学生回答的转写文本 |
| `feedback` | string | 针对该题的简短反馈 (中文) |

## 3️⃣ 家长端 H5 报告字段

> 来源：`backend/src/use_cases/parent_report.py` → `ParentReportData`  
> 前端类型：`frontend/parent-h5/src/types.ts` → `ParentReportData`

### 完整数据结构

```typescript
interface ParentReportData {
  student: StudentInfo;
  overall: OverallScore;
  radar: RadarDimension[];    // 5 维融合后的雷达图数据
  part1: Part1Detail;
  part2: Part2Detail;
  suggestion: Suggestion;
}
```

### 各子结构详解

#### `StudentInfo` - 学生信息

| 字段名 | 类型 | 说明 |
|-------|------|------|
| `name` | string | 学生姓名 |
| `level` | string | 测试等级，如 "Level 2" |

#### `OverallScore` - 总分信息

| 字段名 | 类型 | 范围 | 说明 |
|-------|------|------|------|
| `total_score` | number | 0-100 | 综合总分 (Part1 + Part2 平均) |
| `star_level` | number | 1-5 | 星级评定 |

#### `RadarDimension[]` - 五维雷达图 (融合后)

| 字段名 | 类型 | 说明 |
|-------|------|------|
| `subject` | string | 维度名称：'流利度', '发音', '自信度', '词汇', '整句输出' |
| `score` | number | 融合后分数 (0-100) |
| `fullMark` | number | 满分 (固定为 100) |
| `icon` | string | 图标标识：'fluency', 'pronunciation', 'confidence', 'vocab', 'sentence' |
| `comment` | string | 等级评语 |
| `tags` | string[] | 标签，如 ["节奏清晰", "断句准确"] |

#### `Part1Detail` - Part 1 详情

| 字段名 | 类型 | 说明 |
|-------|------|------|
| `score` | number | Part 1 总分 (0-100) |
| `words` | WordStatus[] | 单词列表 |

##### `WordStatus` - 单词状态

| 字段名 | 类型 | 说明 |
|-------|------|------|
| `text` | string | 单词内容 |
| `status` | enum | 状态：'perfect' / 'unclear' / 'failed' |
| `score` | number | 单词得分 (0-100)，可选 |

**状态转换规则：**
- `score >= 80` → `'perfect'` (绿色)
- `50 <= score < 80` → `'unclear'` (黄色)
- `score < 50` → `'failed'` (红色)

#### `Part2Detail` - Part 2 详情

| 字段名 | 类型 | 说明 |
|-------|------|------|
| `score` | number | Part 2 总分 (0-100) |
| `best_sample` | DialogueSample \| null | 最佳表现样例 |
| `weak_sample` | DialogueSample \| null | 需改进样例 |
| `transcript` | string | 完整转写文本 |

##### `DialogueSample` - 对话样例

| 字段名 | 类型 | 说明 |
|-------|------|------|
| `question_no` | number | 题号 |
| `question` | string | 问题内容 |
| `answer` | string | 学生回答 |
| `score` | string | 等级：'S', 'A', 'B', 'C' |
| `feedback` | string | 评语反馈 |

#### `Suggestion` - 学习建议

| 字段名 | 类型 | 说明 |
|-------|------|------|
| `highlights` | string[] | 亮点 (1-2 条) |
| `weaknesses` | string[] | 短板 (1-2 条) |
| `plan` | string[] | 练习计划 (3 条) |

## 4️⃣ 分数融合策略

> 来源：`backend/src/use_cases/parent_report.py` → `ScoreFusionService`

### 融合公式

| 家长端维度 | 融合公式 | 说明 |
|-----------|---------|------|
| **流利度** | `Part1_Fluency × 0.4 + Part2_Fluency × 0.6` | Part2 权重更高 (问答更体现流利度) |
| **发音** | `Part1_Pronunciation × 0.4 + Part2_Pronunciation × 0.6` | Part2 权重更高 |
| **自信度** | `Part2_Confidence` | 仅 Part2 有此维度 |
| **词汇** | `Part1_Accuracy × 0.3 + Part2_Vocabulary × 0.7` | Part1 准确度反映基础词汇能力 |
| **整句输出** | `Part1_Integrity × 0.2 + Part2_Sentence × 0.8` | Part1 完整度反映基础句感 |

### 融合逻辑说明

- 当某维度只有一方有分数时，直接使用该分数 (不做权重计算)
- 当双方分数都为 0 时，返回 0

## 5️⃣ LLM 调用架构

### 使用的模型

| 功能模块 | 模型 | 价格 (元/百万 Tokens) | 输出方式 |
|---------|------|----------------------|---------|
| Part 1 评测 | `qwen3-omni-flash` | - | JSON |
| Part 2 评测 | `qwen3-omni-flash` | - | JSON |
| **测评汇总分析** | `qwen-plus` | 输入 0.8 / 输出 2 | **结构化输出** |
| **报告解读** | `qwen-plus` | 输入 0.8 / 输出 2 | **结构化输出** |

### 测评汇总分析 (给家长看)

> 来源：`backend/src/adapters/gateways/qwen_client.py` → `generate_summary_analysis()`

**JSON Schema (结构化输出):**

```json
{
  "type": "object",
  "properties": {
    "highlights": {
      "type": "array",
      "items": {"type": "string"},
      "minItems": 1, "maxItems": 2,
      "description": "1-2个最突出的亮点"
    },
    "weaknesses": {
      "type": "array",
      "items": {"type": "string"},
      "minItems": 1, "maxItems": 2,
      "description": "1-2个需要提升的方向"
    },
    "weekly_plan": {
      "type": "array",
      "items": {"type": "string"},
      "minItems": 3, "maxItems": 3,
      "description": "3条本周练习建议"
    }
  },
  "required": ["highlights", "weaknesses", "weekly_plan"]
}
```

**输出示例:**

```json
{
  "highlights": ["发音清晰，元音饱满", "能够自信地回答长问题"],

  ]
}
```
